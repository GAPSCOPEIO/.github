# Contributing to GapScope repos

1. Read `brain` first.
2. Branch from `main`: `tyler/<topic>`, `caleb/<topic>` or `claude/<topic>`.
3. Open a draft pull request. Fill in the template.
4. Squash merge. The branch is deleted after merge.
5. Who merges: Tyler merges `gapscope`. Caleb merges `lab`. Either merges `brain`.
6. Git holds text and code only. PDFs, video and large images live outside git. App assets the build needs (`public/`) are the exception.
7. No secrets, no client data, no PII in any repo. Name env keys; never paste values.
